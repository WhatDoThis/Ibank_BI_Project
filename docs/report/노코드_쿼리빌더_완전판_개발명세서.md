## 1. 프로젝트 개요

### 1.1 목적
SQL을 모르는 사용자가 대시보드와 리포트를 위한 데이터 쿼리를 직관적으로 작성할 수 있는 노코드 쿼리 빌더 개발

### 1.2 핵심 목표
- **자동화**: 테이블 간 관계를 자동으로 감지하여 JOIN 생성
- **정확성**: 명명 규칙 기반으로 98% 이상의 정확도 달성
- **단순성**: 드래그 앤 드롭과 선택만으로 복잡한 쿼리 생성
- **안전성**: LEFT JOIN 기본 사용으로 데이터 손실 방지

### 1.3 타겟 사용자
- SQL 문법을 모르는 마케터, 기획자, 분석가
- 대시보드와 리포트 작성이 필요한 비개발자
- Adobe Campaign, Starbucks CRM 등 엔터프라이즈 시스템 사용자

### 1.4 사용 시나리오
```
사용자 행동:
1. 테이블 선택 (members, orders 드래그)
2. 자동으로 JOIN 생성됨
3. 필터 추가 (날짜, 상태)
4. 집계 설정 (회원별 주문 수)
5. 실행 → 결과 확인

소요 시간: 2분
```

### 1.5 대시보드/리포트 쿼리 특성
- 2~4개 테이블 JOIN (복잡하지 않음)
- WHERE 필터 (날짜, 상태)
- GROUP BY 집계 (개수, 합계, 평균)
- ORDER BY 정렬
- LIMIT으로 상위 N개

**중요**: 서브쿼리, Window 함수, 복잡한 CASE문 등 고급 SQL 기능은 대시보드/리포트에서 거의 사용하지 않음

## 3. 데이터베이스 명명 규칙

### 3.1 필수 명명 규칙
```
규칙:
1. 테이블명: 복수형 snake_case (예: members, order_details)
2. Primary Key: 항상 'id' 사용
3. Foreign Key: {참조테이블단수}_id (예: member_id, product_id)
4. 타임스탬프: created_at, updated_at
```

### 3.2 예시

#### 올바른 스키마
```sql
-- 회원 테이블
CREATE TABLE members (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(255),
  member_grade VARCHAR(20),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 주문 테이블
CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  member_id INTEGER,  -- members.id 참조
  order_date TIMESTAMP,
  total_amount DECIMAL(10,2),
  status VARCHAR(20),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 주문 상세 테이블
CREATE TABLE order_details (
  id SERIAL PRIMARY KEY,
  order_id INTEGER,    -- orders.id 참조
  product_id INTEGER,  -- products.id 참조
  quantity INTEGER,
  price DECIMAL(10,2),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 상품 테이블
CREATE TABLE products (
  id SERIAL PRIMARY KEY,
  product_name VARCHAR(200),
  category VARCHAR(50),
  price DECIMAL(10,2),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 잘못된 스키마 (경고 발생)
```sql
-- ❌ 잘못된 예시
CREATE TABLE member (              -- ❌ 단수형
  member_id SERIAL PRIMARY KEY,    -- ❌ PK는 'id'여야 함
  memberId INTEGER                 -- ❌ camelCase
);

CREATE TABLE campaigns (
  campaign_id SERIAL PRIMARY KEY   -- ❌ PK는 'id'여야 함
);
```

## 4. 자동 JOIN 감지 시스템

### 4.1 감지 우선순위

#### 1순위: 외래키 패턴 매칭 (신뢰도: HIGH)
```typescript
패턴: {테이블명단수}_id → {테이블명복수}.id

예시:
- orders.member_id → members.id
- order_details.product_id → products.id
- deliveries.campaign_id → campaigns.id

감지 로직:
1. 컬럼명이 "_id"로 끝나는지 확인
2. "_id" 제거 후 복수형으로 변환 (member → members)
3. 해당 테이블이 존재하는지 확인
4. 해당 테이블에 'id' 컬럼이 있는지 확인
5. 매칭 성공
```

#### 2순위: 동일 컬럼명 + 동일 타입 (신뢰도: MEDIUM)
```typescript
조건:
1. 두 테이블에 같은 이름의 컬럼 존재
2. 데이터 타입이 동일
3. 'id', 'created_at', 'updated_at' 제외

케이스 1: 참조 테이블이 존재하는 경우
- deliveries.campaign_id ← campaigns 테이블 존재
- tracking_events.campaign_id ← campaigns 테이블 존재
→ 각각 campaigns.id를 참조 (직접 연결 안함)

케이스 2: 참조 테이블이 없는 경우
- deliveries.campaign_id
- tracking_events.campaign_id
- campaigns 테이블 없음
→ 두 테이블을 campaign_id로 직접 연결
→ 신뢰도 MEDIUM으로 사용자 확인 필요
```

#### 3순위: 데이터 샘플링 분석 (신뢰도: MEDIUM/LOW)
```typescript
방법:
1. 각 테이블에서 1000건씩 샘플링
2. 컬럼 값 겹침 비율 계산
3. 70% 이상 겹치면 관계로 판단

SQL 예시:
WITH t1_sample AS (
  SELECT DISTINCT col1 FROM table1 LIMIT 1000
),
t2_sample AS (
  SELECT DISTINCT col2 FROM table2 LIMIT 1000
)
SELECT 
  COUNT(*) FILTER (WHERE t1.col1 IN (SELECT col2 FROM t2_sample)) 
  / COUNT(*)::float as overlap_ratio
FROM t1_sample t1

신뢰도:
- 90% 이상 겹침: HIGH
- 70~90% 겹침: MEDIUM
- 50~70% 겹침: LOW
```

### 4.2 복합 JOIN 조건 감지
```typescript
상황:
- 두 테이블에서 2개 이상의 컬럼이 동시에 매칭되는 경우
- 예: order_id + order_date (파티션 키)

감지 로직:
1. 모든 매칭 컬럼 찾기
2. {테이블명}_id 패턴과 date/time 컬럼이 함께 있으면 복합 키로 판단
3. 단일 조건으로 중복 발생 여부 검증
4. 복합 조건으로 중복 해결되면 복합 JOIN 제안

예시:
orders.order_id = order_details.order_id (단일)
→ 중복 발생 확인
orders.order_id = order_details.order_id 
AND orders.order_date = order_details.order_date (복합)
→ 중복 해결됨
→ 복합 조건 권장
```

### 4.3 신뢰도 레벨 표시
```typescript
enum Confidence {
  HIGH = 'HIGH',     // 🟢 녹색 - FK 패턴 명확
  MEDIUM = 'MEDIUM', // 🟡 노란색 - 동일 컬럼명, 데이터 검증 필요
  LOW = 'LOW'        // 🔴 빨간색 - 통계적 유사도만
}

interface DetectedRelationship {
  fromTable: string;
  fromColumn: string;
  toTable: string;
  toColumn: string;
  confidence: Confidence;
  reason: string;  // 감지 이유 설명
  cardinality: '1:1' | '1:N' | 'N:1' | 'N:N';
  dataOverlapRatio?: number;  // 데이터 겹침 비율 (0~1)
}
```

## 5. 쿼리 구성 요소

### 5.1 전체 쿼리 구조
```typescript
interface DashboardQuery {
  // 1. 테이블 선택

  // 2. JOIN 설정
  joins: JoinConfig[];
  
  // 3. 컬럼 선택 (선택사항, 기본은 *)

  // 4. 필터 (WHERE)
  filters: Filter[];
  
  // 5. 집계 (GROUP BY + 집계 함수)
  aggregation?: Aggregation;
  
  // 6. 정렬 (ORDER BY)
  orderBy: Sort[];
  
  // 7. 제한 (LIMIT)
  limit?: number;
}
```

### 5.2 JOIN 설정
```typescript
interface JoinConfig {
  leftTable: string;
  rightTable: string;
  joinType: 'LEFT' | 'INNER' | 'RIGHT';
  conditions: JoinCondition[];
  logicalOperator: 'AND' | 'OR';  // 조건 간 연결
}

interface JoinCondition {
  leftColumn: string;
  operator: '=' | '!=' | '>' | '<' | '>=' | '<=';
  rightColumn: string;
}

// 예시: 단일 조건 JOIN
{
  leftTable: 'members',
  rightTable: 'orders',
  joinType: 'LEFT',
  conditions: [
    { leftColumn: 'id', operator: '=', rightColumn: 'member_id' }
  ],
  logicalOperator: 'AND'
}

// 예시: 복합 조건 JOIN
{
  leftTable: 'orders',
  rightTable: 'order_details',
  joinType: 'LEFT',
  conditions: [
    { leftColumn: 'order_id', operator: '=', rightColumn: 'order_id' },
    { leftColumn: 'order_date', operator: '=', rightColumn: 'order_date' }
  ],
  logicalOperator: 'AND'
}
```

### 5.3 필터 (WHERE 절)
```typescript
interface Filter {
  column: string;  // 'table.column' 형식
  operator: FilterOperator;
  value: any;
  logicalOperator?: 'AND' | 'OR';  // 다음 필터와의 연결
}

type FilterOperator = 
  | '='           // 같음
  | '!='          // 다름
  | '>'           // 크다
  | '<'           // 작다
  | '>='          // 크거나 같다
  | '<='          // 작거나 같다
  | 'BETWEEN'     // 범위
  | 'IN'          // 목록 중 하나
  | 'LIKE'        // 패턴 매칭
  | 'IS NULL'     // NULL
  | 'IS NOT NULL' // NOT NULL

// 예시
filters: [
  {
    column: 'orders.order_date',
    operator: '>=',
    value: '2024-01-01',
    logicalOperator: 'AND'
  },
  {
    column: 'orders.status',
    operator: 'IN',
    value: ['COMPLETED', 'SHIPPED'],
    logicalOperator: 'AND'
  },
  {
    column: 'members.member_grade',
    operator: '=',
    value: 'GOLD'
  }
]

// 생성되는 SQL
WHERE orders.order_date >= '2024-01-01'
  AND orders.status IN ('COMPLETED', 'SHIPPED')
  AND members.member_grade = 'GOLD'
```

### 5.4 집계 (GROUP BY + 집계 함수)
```typescript
interface Aggregation {
  groupBy: string[];  // GROUP BY 컬럼들
  metrics: Metric[];  // 집계 함수들
}

interface Metric {
  column: string;
  function: AggregateFunction;
  alias: string;  // 결과 컬럼명
}

type AggregateFunction = 
  | 'COUNT'          // 개수
  | 'COUNT_DISTINCT' // 고유 개수
  | 'SUM'            // 합계
  | 'AVG'            // 평균
  | 'MIN'            // 최소값
  | 'MAX'            // 최대값

// 예시
aggregation: {
  groupBy: ['members.member_grade'],
  metrics: [
    { column: '*', function: 'COUNT', alias: 'member_count' },
    { column: 'orders.total_amount', function: 'SUM', alias: 'total_sales' },
    { column: 'orders.total_amount', function: 'AVG', alias: 'avg_sales' },
    { column: 'orders.member_id', function: 'COUNT_DISTINCT', alias: 'unique_buyers' }
  ]
}

// 생성되는 SQL
SELECT 
  members.member_grade,
  COUNT(*) as member_count,
  SUM(orders.total_amount) as total_sales,
  AVG(orders.total_amount) as avg_sales,
  COUNT(DISTINCT orders.member_id) as unique_buyers
FROM ...
GROUP BY members.member_grade
```

```typescript
interface Sort {
```

```typescript
class SchemaAnalyzer {
  async analyzeDatabase(connectionString: string): Promise<Map<string, TableSchema>> {
    const schemas = new Map<string, TableSchema>();
    
    // 1. 모든 테이블 목록 가져오기
    const tables = await this.getTables();
    
    for (const tableName of tables) {
      // 2. 테이블별 상세 정보
      const columns = await this.getColumns(tableName);
      const primaryKeys = await this.getPrimaryKeys(tableName);
      const foreignKeys = await this.getForeignKeys(tableName);
      const rowCount = await this.getRowCount(tableName);
      
      schemas.set(tableName, {
        tableName,
        columns,
        primaryKeys,
        foreignKeys,
        rowCount
      });
    }
    
    return schemas;
  }
  
  private async getTables(): Promise<string[]> {
    const query = `
      SELECT table_name 
      FROM information_schema.tables 
      WHERE table_schema = 'public' 
        AND table_type = 'BASE TABLE'
      ORDER BY table_name
    `;
    const result = await this.db.query(query);
    return result.rows.map(r => r.table_name);
  }
  
  private async getColumns(tableName: string): Promise<ColumnInfo[]> {
    const query = `
      SELECT 
        column_name,
        data_type,
        is_nullable,
        column_default
      FROM information_schema.columns
      WHERE table_schema = 'public'
        AND table_name = $1
      ORDER BY ordinal_position
    `;
    const result = await this.db.query(query, [tableName]);
    
    return result.rows.map(row => ({
      name: row.column_name,
      type: row.data_type,
      nullable: row.is_nullable === 'YES',
      unique: false,  // 별도 쿼리 필요
      defaultValue: row.column_default
    }));
  }
  
  private async getPrimaryKeys(tableName: string): Promise<string[]> {
    const query = `
      SELECT kcu.column_name
      FROM information_schema.table_constraints tc
      JOIN information_schema.key_column_usage kcu
        ON tc.constraint_name = kcu.constraint_name
      WHERE tc.table_schema = 'public'
        AND tc.table_name = $1
        AND tc.constraint_type = 'PRIMARY KEY'
    `;
    const result = await this.db.query(query, [tableName]);
    return result.rows.map(r => r.column_name);
  }
  
  private async getForeignKeys(tableName: string): Promise<ForeignKeyInfo[]> {
    const query = `
      SELECT
        kcu.column_name,
        ccu.table_name AS referenced_table,
        ccu.column_name AS referenced_column
      FROM information_schema.table_constraints tc
      JOIN information_schema.key_column_usage kcu
        ON tc.constraint_name = kcu.constraint_name
      JOIN information_schema.constraint_column_usage ccu
        ON ccu.constraint_name = tc.constraint_name
      WHERE tc.table_schema = 'public'
        AND tc.table_name = $1
        AND tc.constraint_type = 'FOREIGN KEY'
    `;
    const result = await this.db.query(query, [tableName]);
    
    return result.rows.map(row => ({
      column: row.column_name,
      referencedTable: row.referenced_table,
      referencedColumn: row.referenced_column
    }));
  }
  
  private async getRowCount(tableName: string): Promise<number> {
    const query = `SELECT COUNT(*) as count FROM ${tableName}`;
    const result = await this.db.query(query);
    return parseInt(result.rows[0].count);
  }
```

```typescript
class RelationshipDetector {
  detectRelationships(schemas: Map<string, TableSchema>): DetectedRelationship[] {
    const results: DetectedRelationship[] = [];
    
    // 1순위: FK 패턴 매칭
    for (const [tableName, schema] of schemas.entries()) {
      for (const column of schema.columns) {
        if (column.name.endsWith('_id') && column.name !== 'id') {
          const referencedTable = this.inferTableName(column.name);
          
          if (schemas.has(referencedTable)) {
            results.push({
              fromTable: tableName,
              fromColumn: column.name,
              toTable: referencedTable,
              toColumn: 'id',
              confidence: 'HIGH',
              reason: `FK pattern: ${column.name} → ${referencedTable}.id`,
              cardinality: 'N:1'
            });
          }
        }
      }
    }
    
    // 2순위: 동일 컬럼명 매칭
    const tables = Array.from(schemas.keys());
    for (let i = 0; i < tables.length; i++) {
      for (let j = i + 1; j < tables.length; j++) {
        const table1 = tables[i];
        const table2 = tables[j];
        const schema1 = schemas.get(table1)!;
        const schema2 = schemas.get(table2)!;
        
        for (const col1 of schema1.columns) {
          for (const col2 of schema2.columns) {
            if (col1.name === col2.name && 
                col1.type === col2.type &&
                col1.name !== 'id' &&
                !col1.name.includes('created') &&
                !col1.name.includes('updated')) {
              
              // 참조 테이블 확인
              if (col1.name.endsWith('_id')) {
                const refTable = this.inferTableName(col1.name);
                if (schemas.has(refTable)) {
                  // 각각 참조 테이블을 참조 (직접 연결 안함)
                  continue;
                }
              }
              
              // 직접 연결
              results.push({
                fromTable: table1,
                fromColumn: col1.name,
                toTable: table2,
                toColumn: col2.name,
                confidence: 'MEDIUM',
                reason: `Same column: ${col1.name}`,
                cardinality: 'N:N'
              });
            }
          }
        }
      }
    }
    
    return results;
  }
  
  private inferTableName(fkColumnName: string): string {
    // member_id → members
    // product_id → products
    const baseName = fkColumnName.replace(/_id$/, '');
    return `${baseName}s`;  // 단순 복수형 변환
  }
}
```

### 8.3 다중 JOIN 순서 결정 (최소 신장 트리)

```typescript
class JoinOrderOptimizer {
  optimizeJoinOrder(
    selectedTables: string[],
    relationships: DetectedRelationship[]
  ): JoinConfig[] {
    
    // 1. 관계 그래프 생성
    const graph = this.buildGraph(selectedTables, relationships);
    
    // 2. 최소 신장 트리로 연결 경로 찾기
    const edges = this.findMinimumSpanningTree(graph);
    
    // 3. 베이스 테이블 선택
    const baseTable = this.selectBaseTable(graph, edges);
    
    // 4. BFS로 JOIN 순서 결정
    const joins = this.buildJoinSequence(baseTable, edges);
    
    return joins;
  }
  
  private buildGraph(
    tables: string[],
    relationships: DetectedRelationship[]
  ): RelationshipGraph {
    const edges: GraphEdge[] = [];
    
    for (const rel of relationships) {
      if (tables.includes(rel.fromTable) && tables.includes(rel.toTable)) {
        const weight = rel.confidence === 'HIGH' ? 3 :
                       rel.confidence === 'MEDIUM' ? 2 : 1;
        
        edges.push({
          from: rel.fromTable,
          to: rel.toTable,
          fromColumn: rel.fromColumn,
          toColumn: rel.toColumn,
          weight
        });
      }
    }
    
    return { nodes: tables, edges };
  }
  
  private findMinimumSpanningTree(graph: RelationshipGraph): GraphEdge[] {
    const visited = new Set<string>();
    const result: GraphEdge[] = [];
    
    if (graph.nodes.length === 0) return result;
    
    // 시작 노드: 가장 많이 연결된 테이블
    const startNode = this.findMostConnectedNode(graph);
    visited.add(startNode);
    
    // Prim's Algorithm
    while (visited.size < graph.nodes.length) {
      let bestEdge: GraphEdge | null = null;
      let maxWeight = -1;
      
      // 방문한 노드에서 나가는 간선 중 최고 가중치
      for (const edge of graph.edges) {
        const fromVisited = visited.has(edge.from);
        const toVisited = visited.has(edge.to);
        
        if (fromVisited !== toVisited) {  // 한쪽만 방문
          if (edge.weight > maxWeight) {
            maxWeight = edge.weight;
            bestEdge = edge;
          }
        }
      }
      
      if (bestEdge) {
        result.push(bestEdge);
        visited.add(bestEdge.from);
        visited.add(bestEdge.to);
      } else {
        break;  // 연결 불가능한 테이블 존재
      }
    }
    
    return result;
  }
  
  private findMostConnectedNode(graph: RelationshipGraph): string {
    const connectionCount = new Map<string, number>();
    
    for (const node of graph.nodes) {
      connectionCount.set(node, 0);
    }
    
    for (const edge of graph.edges) {
      connectionCount.set(edge.from, (connectionCount.get(edge.from) || 0) + 1);
      connectionCount.set(edge.to, (connectionCount.get(edge.to) || 0) + 1);
    }
    
    let maxNode = graph.nodes[0];
    let maxCount = 0;
    
    for (const [node, count] of connectionCount.entries()) {
      if (count > maxCount) {
        maxCount = count;
        maxNode = node;
      }
    }
    
    return maxNode;
  }
  
  private selectBaseTable(
    graph: RelationshipGraph,
    edges: GraphEdge[]
  ): string {
    // 가장 적게 참조되는 테이블 = 상위 테이블
    const referenceCounts = new Map<string, number>();
    
    for (const node of graph.nodes) {
      referenceCounts.set(node, 0);
    }
    
    for (const edge of edges) {
      referenceCounts.set(edge.to, (referenceCounts.get(edge.to) || 0) + 1);
    }
    
    let minCount = Infinity;
    let baseTable = graph.nodes[0];
    
    for (const [table, count] of referenceCounts.entries()) {
      if (count < minCount) {
        minCount = count;
        baseTable = table;
      }
    }
    
    return baseTable;
  }
  
  private buildJoinSequence(
    baseTable: string,
    edges: GraphEdge[]
  ): JoinConfig[] {
    const joins: JoinConfig[] = [];
    const processed = new Set<string>();
    processed.add(baseTable);
    
    // BFS
    const queue: string[] = [baseTable];
    
    while (queue.length > 0) {
      const currentTable = queue.shift()!;
      
      // 현재 테이블에서 나가는 간선
      for (const edge of edges) {
        if (edge.from === currentTable && !processed.has(edge.to)) {
          joins.push({
            leftTable: edge.from,
            rightTable: edge.to,
            joinType: 'LEFT',
            conditions: [
              {
                leftColumn: edge.fromColumn,
                operator: '=',
                rightColumn: edge.toColumn
              }
            ],
            logicalOperator: 'AND'
          });
          
          processed.add(edge.to);
          queue.push(edge.to);
        }
        
        // 들어오는 간선
        if (edge.to === currentTable && !processed.has(edge.from)) {
          joins.push({
            leftTable: edge.from,
            rightTable: edge.to,
            joinType: 'LEFT',
            conditions: [
              {
                leftColumn: edge.fromColumn,
                operator: '=',
                rightColumn: edge.toColumn
              }
            ],
            logicalOperator: 'AND'
          });
          
          processed.add(edge.from);
          queue.push(edge.from);
        }
      }
    }
    
    return joins;
  }
}
```

### 8.4 SQL 쿼리 생성

```typescript
class QueryBuilder {
  buildQuery(query: DashboardQuery): string {
    let sql = '';
    
    // SELECT 절
    sql += this.buildSelectClause(query);
    
    // FROM 절
    sql += this.buildFromClause(query);
    
    // JOIN 절
    sql += this.buildJoinClauses(query.joins);
    
    // WHERE 절
    if (query.filters.length > 0) {
      sql += this.buildWhereClause(query.filters);
    }
    
    // GROUP BY 절
    if (query.aggregation) {
      sql += this.buildGroupByClause(query.aggregation);
    }
    
    // ORDER BY 절
    if (query.orderBy.length > 0) {
      sql += this.buildOrderByClause(query.orderBy);
    }
    
    // LIMIT 절
    if (query.limit) {
      sql += `\nLIMIT ${query.limit}`;
    }
    
    return sql;
  }
  
  private buildSelectClause(query: DashboardQuery): string {
    let sql = 'SELECT\n';
    
    if (query.aggregation) {
      // 집계 쿼리
      const columns: string[] = [];
      
      // GROUP BY 컬럼
      for (const col of query.aggregation.groupBy) {
        columns.push(`  ${col}`);
      }
      
      // 집계 함수
      for (const metric of query.aggregation.metrics) {
        const func = metric.function === 'COUNT_DISTINCT' 
          ? `COUNT(DISTINCT ${metric.column})`
          : `${metric.function}(${metric.column})`;
        columns.push(`  ${func} as ${metric.alias}`);
      }
      
      sql += columns.join(',\n');
    } else if (query.selectedColumns && query.selectedColumns.length > 0) {
      // 특정 컬럼만
      const columns = query.selectedColumns.map(col => {
        const colName = `${col.table}.${col.column}`;
        return col.alias ? `  ${colName} as ${col.alias}` : `  ${colName}`;
      });
      sql += columns.join(',\n');
    } else {
      // 전체 컬럼
      sql += '  *';
    }
    
    return sql;
  }
  
  private buildFromClause(query: DashboardQuery): string {
    const baseTable = query.tables[0];  // 첫 번째 테이블
    return `\nFROM ${baseTable}`;
  }
  
  private buildJoinClauses(joins: JoinConfig[]): string {
    let sql = '';
    
    for (const join of joins) {
      sql += `\n${join.joinType} JOIN ${join.rightTable}`;
      sql += '\n  ON ';
      
      const conditions = join.conditions.map(cond => 
        `${join.leftTable}.${cond.leftColumn} ${cond.operator} ${join.rightTable}.${cond.rightColumn}`
      );
      
      sql += conditions.join(`\n  ${join.logicalOperator} `);
    }
    
    return sql;
  }
  
  private buildWhereClause(filters: Filter[]): string {
    let sql = '\nWHERE ';
    
    const conditions: string[] = [];
    
    for (let i = 0; i < filters.length; i++) {
      const filter = filters[i];
      let condition = '';
      
      if (i > 0 && filter.logicalOperator) {
        condition += `${filter.logicalOperator} `;
      }
      
      switch (filter.operator) {
        case 'IS NULL':
        case 'IS NOT NULL':
          condition += `${filter.column} ${filter.operator}`;
          break;
        
        case 'IN':
          const values = Array.isArray(filter.value) 
            ? filter.value.map(v => `'${v}'`).join(', ')
            : filter.value;
          condition += `${filter.column} IN (${values})`;
          break;
        
        case 'BETWEEN':
          condition += `${filter.column} BETWEEN '${filter.value[0]}' AND '${filter.value[1]}'`;
          break;
        
        case 'LIKE':
          condition += `${filter.column} LIKE '%${filter.value}%'`;
          break;
        
        default:
          const value = typeof filter.value === 'string' 
            ? `'${filter.value}'` 
            : filter.value;
          condition += `${filter.column} ${filter.operator} ${value}`;
      }
      
      conditions.push(condition);
    }
    
    sql += conditions.join('\n  ');
    return sql;
  }
  
  private buildGroupByClause(aggregation: Aggregation): string {
    if (aggregation.groupBy.length === 0) return '';
    
    return '\nGROUP BY ' + aggregation.groupBy.join(', ');
  }
  
  private buildOrderByClause(orderBy: Sort[]): string {
    const sorts = orderBy.map(sort => `${sort.column} ${sort.direction}`);
    return '\nORDER BY ' + sorts.join(', ');
  }
}
```

```typescript
interface UserPermissions {
  userId: string;
  allowedTables: string[];
  allowedOperations: ('SELECT' | 'INSERT' | 'UPDATE' | 'DELETE')[];
}

// 쿼리 실행 전 권한 검증
function validatePermissions(
  query: DashboardQuery,
  permissions: UserPermissions
): boolean {
  for (const table of query.tables) {
    if (!permissions.allowedTables.includes(table)) {
      throw new Error(`Access denied to table: ${table}`);
    }
  }
  
  // 대시보드는 SELECT만 허용
  if (!permissions.allowedOperations.includes('SELECT')) {
    throw new Error('SELECT permission required');
  }
  
  return true;
}
```

```typescript
class SchemaCache {
  private cache = new Map<string, TableSchema>();
  private cacheExpiry = 3600000;  // 1시간
  
  async getSchema(tableName: string): Promise<TableSchema> {
    const cached = this.cache.get(tableName);
    
    if (cached && Date.now() - cached.timestamp < this.cacheExpiry) {
      return cached.data;
    }
    
    const schema = await this.fetchSchema(tableName);
    this.cache.set(tableName, {
      data: schema,
      timestamp: Date.now()
    });
    
    return schema;
  }
}
```

## 15. FAQ

**Q: FK 제약조건이 없는 데이터베이스도 작동하나요?**
A: 네, 명명 규칙만 지키면 100% 작동합니다. FK 제약조건은 선택사항입니다.

**Q: 복잡한 서브쿼리가 필요한 경우는?**
A: 대시보드/리포트용으로는 서브쿼리가 거의 필요없습니다. 필요한 경우 DB 뷰로 미리 생성하거나 SQL 직접 편집 모드를 사용하세요.

**Q: 성능이 느린 쿼리는 어떻게 처리하나요?**
A: EXPLAIN 분석 결과를 보여주고, 인덱스 추가를 제안합니다. LIMIT을 강제하거나 샘플링 모드를 제공할 수 있습니다.

**Q: 다른 데이터베이스(MySQL, Oracle)도 지원 가능한가요?**
A: 아키텍처상 가능하지만, 각 DB의 메타데이터 쿼리와 SQL 방언 차이를 처리해야 합니다.

```typescript
import React, { useState } from 'react';
import { useSchemaAnalyzer } from '@/hooks/useSchemaAnalyzer';

interface TableSelectorProps {
  selectedTables: string[];
  onSelect: (tableName: string) => void;
  onDeselect: (tableName: string) => void;
}

export default function TableSelector({
  selectedTables,
  onSelect,
  onDeselect
}: TableSelectorProps) {
  const { tables, isLoading } = useSchemaAnalyzer();
  const [searchTerm, setSearchTerm] = useState('');

  const filteredTables = tables.filter(table =>
    table.tableName.toLowerCase().includes(searchTerm.toLowerCase())
  );

  const handleToggle = (tableName: string) => {
    if (selectedTables.includes(tableName)) {
      onDeselect(tableName);
    } else {
      onSelect(tableName);
    }
  };

  if (isLoading) {
    return <div className="loading">테이블 로딩 중...</div>;
  }

  return (
    <div className="table-selector">
      <input
        type="search"
        placeholder="테이블 검색..."
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
        className="search-input"
      />

      <div className="table-list">
        {filteredTables.map((table) => (
          <div
            key={table.tableName}
            className={`table-item ${
              selectedTables.includes(table.tableName) ? 'selected' : ''
            }`}
            onClick={() => handleToggle(table.tableName)}
          >
            <input
              type="checkbox"
              checked={selectedTables.includes(table.tableName)}
              readOnly
            />
            <div className="table-info">
              <span className="table-name">{table.tableName}</span>
              <span className="row-count">
                {table.rowCount.toLocaleString()} rows
              </span>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
}
```

```typescript
// src/store/queryBuilderStore.ts
import { create } from 'zustand';
import { devtools } from 'zustand/middleware';
import { 
  TableSchema, 
  DetectedRelationship, 
  JoinConfig,
  Filter,
  Aggregation,
  DashboardQuery 
} from '@/types';

interface QueryBuilderState {
  // 스키마 정보
  schemas: Map<string, TableSchema>;
  isLoadingSchemas: boolean;
  
  // 선택된 테이블
  selectedTables: string[];
  
  // 감지된 관계
  detectedRelationships: DetectedRelationship[];
  
  // 쿼리 구성
  joins: JoinConfig[];
  filters: Filter[];
  aggregation: Aggregation | null;
  orderBy: Sort[];
  limit: number | null;
  
  // 쿼리 결과
  sql: string;
  results: any[] | null;
  isExecuting: boolean;
  error: string | null;
  
  // 액션
  setSchemas: (schemas: Map<string, TableSchema>) => void;
  setLoadingSchemas: (loading: boolean) => void;
  
  selectTable: (tableName: string) => void;
  deselectTable: (tableName: string) => void;
  
  setDetectedRelationships: (relationships: DetectedRelationship[]) => void;
  
  setJoins: (joins: JoinConfig[]) => void;
  updateJoin: (index: number, join: JoinConfig) => void;
  deleteJoin: (index: number) => void;
  
  addFilter: () => void;
  updateFilter: (index: number, filter: Filter) => void;
  removeFilter: (index: number) => void;
  
  setAggregation: (aggregation: Aggregation | null) => void;
  
  setSql: (sql: string) => void;
  setResults: (results: any[] | null) => void;
  setExecuting: (executing: boolean) => void;
  setError: (error: string | null) => void;
  
  reset: () => void;
}

export const useQueryBuilderStore = create<QueryBuilderState>()(
  devtools(
    (set, get) => ({
      // 초기 상태
      schemas: new Map(),
      isLoadingSchemas: false,
      selectedTables: [],
      detectedRelationships: [],
      joins: [],
      filters: [],
      aggregation: null,
      orderBy: [],
      limit: null,
      sql: '',
      results: null,
      isExecuting: false,
      error: null,
      
      // 액션 구현
      setSchemas: (schemas) => set({ schemas }),
      setLoadingSchemas: (loading) => set({ isLoadingSchemas: loading }),
      
      selectTable: (tableName) => {
        const { selectedTables } = get();
        if (!selectedTables.includes(tableName)) {
          set({ selectedTables: [...selectedTables, tableName] });
        }
      },
      
      deselectTable: (tableName) => {
        const { selectedTables } = get();
        set({ 
          selectedTables: selectedTables.filter(t => t !== tableName)
        });
      },
      
      setDetectedRelationships: (relationships) => 
        set({ detectedRelationships: relationships }),
      
      setJoins: (joins) => set({ joins }),
      
      updateJoin: (index, join) => {
        const { joins } = get();
        const newJoins = [...joins];
        newJoins[index] = join;
        set({ joins: newJoins });
      },
      
      deleteJoin: (index) => {
        const { joins } = get();
        set({ joins: joins.filter((_, i) => i !== index) });
      },
      
      addFilter: () => {
        const { filters } = get();
        set({ 
          filters: [
            ...filters,
            { column: '', operator: '=', value: '' }
          ]
        });
      },
      
      updateFilter: (index, filter) => {
        const { filters } = get();
        const newFilters = [...filters];
        newFilters[index] = filter;
        set({ filters: newFilters });
      },
      
      removeFilter: (index) => {
        const { filters } = get();
        set({ filters: filters.filter((_, i) => i !== index) });
      },
      
      setAggregation: (aggregation) => set({ aggregation }),
      
      setSql: (sql) => set({ sql }),
      setResults: (results) => set({ results }),
      setExecuting: (executing) => set({ isExecuting: executing }),
      setError: (error) => set({ error }),
      
      reset: () => set({
        selectedTables: [],
        detectedRelationships: [],
        joins: [],
        filters: [],
        aggregation: null,
        orderBy: [],
        limit: null,
        sql: '',
        results: null,
        error: null
      })
    }),
    { name: 'QueryBuilder' }
  )
);
```

```typescript
      results: result.rows,
      rowCount: result.rowCount
    });
  } catch (error) {
    if (error.message === 'Query timeout') {
      res.status(408).json({ error: 'Query execution timeout' });
    } else {
      res.status(500).json({ error: error.message });
    }
  }
});

// POST /api/query/analyze
router.post('/analyze', async (req, res) => {
  try {
    const { sql } = req.body;
    
    const explainQuery = `EXPLAIN (FORMAT JSON) ${sql}`;
    const result = await db.query(explainQuery);
    
    const analysis = analyzeQueryPlan(result.rows[0]);
    
    res.json(analysis);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

export default router;
```

### 19.1 useQueryBuilder (메인 훅)

```typescript
// src/hooks/useQueryBuilder.ts
import { useEffect, useCallback } from 'react';
import { useQueryBuilderStore } from '@/store/queryBuilderStore';
import { useSchemaAnalyzer } from './useSchemaAnalyzer';
import { useRelationshipDetector } from './useRelationshipDetector';
import { useQueryExecutor } from './useQueryExecutor';
import { QueryBuilder } from '@/utils/queryBuilder';

export function useQueryBuilder() {
  const store = useQueryBuilderStore();
  const { detectRelationships } = useRelationshipDetector();
  const { executeQuery: runQuery } = useQueryExecutor();
  
  // 테이블 선택 시 자동으로 관계 감지
  useEffect(() => {
    if (store.selectedTables.length >= 2) {
      detectRelationships(store.selectedTables);
    }
  }, [store.selectedTables]);
  
  // 쿼리 구성 변경 시 SQL 자동 생성
  useEffect(() => {
    const builder = new QueryBuilder();
    const query = {
      tables: store.selectedTables,
      joins: store.joins,
      filters: store.filters,
      aggregation: store.aggregation,
      orderBy: store.orderBy,
      limit: store.limit
    };
    
    try {
      const sql = builder.buildQuery(query);
      store.setSql(sql);
    } catch (error) {
      store.setError(error.message);
    }
  }, [
    store.selectedTables,
    store.joins,
    store.filters,
    store.aggregation,
    store.orderBy,
    store.limit
  ]);
  
  const executeQuery = useCallback(async () => {
    if (!store.sql) return;
    
    store.setExecuting(true);
    store.setError(null);
    
    try {
      const results = await runQuery(store.sql);
      store.setResults(results);
    } catch (error) {
      store.setError(error.message);
    } finally {
      store.setExecuting(false);
    }
  }, [store.sql]);
  
  return {
    // 상태
    selectedTables: store.selectedTables,
    detectedJoins: store.joins,
    filters: store.filters,
    aggregation: store.aggregation,
    sql: store.sql,
    results: store.results,
    isLoading: store.isExecuting,
    error: store.error,
    
    // 액션
    selectTable: store.selectTable,
    deselectTable: store.deselectTable,
    updateJoin: store.updateJoin,
    addFilter: store.addFilter,
    updateFilter: store.updateFilter,
    removeFilter: store.removeFilter,
    updateAggregation: store.setAggregation,
    executeQuery,
    reset: store.reset
  };
}
```

### 19.3 useRelationshipDetector

```typescript
// src/hooks/useRelationshipDetector.ts
import { useCallback } from 'react';
import { useMutation } from '@tanstack/react-query';
import { useQueryBuilderStore } from '@/store/queryBuilderStore';
import { relationshipApi } from '@/api/relationships';
import { JoinOrderOptimizer } from '@/utils/joinOptimizer';

export function useRelationshipDetector() {
  const { 
    setDetectedRelationships, 
    setJoins,
    schemas 
  } = useQueryBuilderStore();
  
  const detectMutation = useMutation({
    mutationFn: relationshipApi.detectRelationships,
    onSuccess: (relationships) => {
      setDetectedRelationships(relationships);
      
      // 자동으로 JOIN 순서 최적화
      const optimizer = new JoinOrderOptimizer();
      const selectedTables = useQueryBuilderStore.getState().selectedTables;
      const joins = optimizer.optimizeJoinOrder(selectedTables, relationships);
      
      setJoins(joins);
    }
  });
  
  const detectRelationships = useCallback(async (tableNames: string[]) => {
    await detectMutation.mutateAsync(tableNames);
  }, []);
  
  return {
    detectRelationships,
    isDetecting: detectMutation.isPending,
    error: detectMutation.error
  };
}
```
