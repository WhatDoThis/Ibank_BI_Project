# I1_ 파생 테이블 정의

원천 테이블: **campaigns**, **test_coupons_data**, **test_deliveries_data**, **test_delivery_tracking**, **workflows** (총 5개)  
파생 테이블명 규칙: **I1_** 접두사. (DB 저장 시 소문자: i1_xxx)

---

## 원천 테이블 스키마 요약

| 테이블 | 주요 컬럼 |
|--------|------------|
| campaigns | id, campaign_internal_name, campaign_label, created, last_modified, created_at, updated_at |
| test_coupons_data | id, campaign_id, workflow_id, recipient_id, coupon_id, coupon_date, campaign_label, workflow_label, created, last_modified |
| test_deliveries_data | id, delivery_id, delivery_channel, delivery_status, delivery_date, campaign_id, workflow_id, campaign_label, workflow_label, recipient_id, created, last_modified |
| test_delivery_tracking | id, delivery_id, recipient_id, tracking_type, tracking_date, created_at, updated_at |
| workflows | id, workflow_internal_name, workflow_label, campaign_id, created, last_modified, created_at, updated_at |

**관계**: workflows.campaign_id → campaigns.id, test_coupons_data/test_deliveries_data의 campaign_id → campaigns.id, workflow_id → workflows.id, test_delivery_tracking.delivery_id → test_deliveries_data.id.

---

## I1_ 파생 테이블 목록

### 1. I1_campaign_workflow_list
- **설명**: 캠페인별 워크플로우 목록
- **원천**: campaigns ⋈ workflows (workflows.campaign_id = campaigns.id)
- **용도**: 캠페인·워크플로우 매핑 조회

### 2. I1_delivery_tracking_joined
- **설명**: 발송 한 건 + 트래킹(오픈/클릭 등) 한 행으로 조인
- **원천**: test_deliveries_data ⋈ test_delivery_tracking (delivery_id → deliveries.id)
- **용도**: 발송 단위별 트래킹 이벤트 분석

### 3. I1_daily_delivery_count
- **설명**: 일별 발송 건수
- **원천**: test_deliveries_data GROUP BY delivery_date, COUNT(*)
- **용도**: 일별 발송량 추이

### 4. I1_campaign_delivery_count
- **설명**: 캠페인별 발송 건수
- **원천**: test_deliveries_data GROUP BY campaign_id, campaign_label, COUNT(*)
- **용도**: 캠페인별 발송량

### 5. I1_workflow_delivery_count
- **설명**: 워크플로우별 발송 건수
- **원천**: test_deliveries_data GROUP BY workflow_id, workflow_label, COUNT(*)
- **용도**: 워크플로우별 발송량

### 6. I1_channel_delivery_count
- **설명**: 채널별 발송 건수
- **원천**: test_deliveries_data GROUP BY delivery_channel, COUNT(*)
- **용도**: 채널별 발송량

### 7. I1_daily_campaign_delivery
- **설명**: 일별·캠페인별 발송 건수
- **원천**: test_deliveries_data GROUP BY delivery_date, campaign_id, campaign_label, COUNT(*)
- **용도**: 일별·캠페인별 추이

### 8. I1_daily_workflow_delivery
- **설명**: 일별·워크플로우별 발송 건수
- **원천**: test_deliveries_data GROUP BY delivery_date, workflow_id, workflow_label, COUNT(*)
- **용도**: 일별·워크플로우별 추이

### 9. I1_tracking_by_type
- **설명**: 발송(delivery)별 트래킹 타입(오픈/클릭 등) 건수
- **원천**: test_delivery_tracking GROUP BY delivery_id, tracking_type, COUNT(*)
- **용도**: 발송당 오픈/클릭 건수

### 10. I1_campaign_daily_channel
- **설명**: 캠페인·일자·채널별 발송 건수
- **원천**: test_deliveries_data GROUP BY campaign_id, campaign_label, delivery_date, delivery_channel, COUNT(*)
- **용도**: 캠페인·일·채널 피벗

### 11. I1_delivery_status_summary
- **설명**: 발송 상태별 건수
- **원천**: test_deliveries_data GROUP BY delivery_status, COUNT(*)
- **용도**: 상태별 집계

### 12. I1_workflow_list_per_campaign
- **설명**: 캠페인별 워크플로우 목록(뷰 수준)
- **원천**: workflows SELECT campaign_id, workflow_id, workflow_internal_name, workflow_label
- **용도**: 캠페인–워크플로우 매핑

### 13. I1_recent_deliveries
- **설명**: 최근 발송 N건(예: 1000건)
- **원천**: test_deliveries_data ORDER BY delivery_date DESC LIMIT 1000
- **용도**: 최근 발송 스냅샷

### 14. I1_delivery_with_campaign_workflow
- **설명**: 발송 + 캠페인 + 워크플로우 컬럼을 한 테이블로
- **원천**: test_deliveries_data ⋈ campaigns ⋈ workflows
- **용도**: 조인 결과 재사용

### 15. I1_tracking_daily_count
- **설명**: 일별·트래킹 타입별 건수
- **원천**: test_delivery_tracking GROUP BY tracking_date, tracking_type, COUNT(*)
- **용도**: 일별 오픈/클릭 등 이벤트 건수

## 생성 방법

- **스크립트**: `scripts/create_I1_derived_tables.py`
  - 실행: 프로젝트 루트에서 `python scripts/create_I1_derived_tables.py`
  - 옵션: `--drop` — 기존 I1_ 테이블을 DROP한 뒤 **23개** 테이블 재생성
  - 위 23개 테이블을 **config의 table_schema**에 `CREATE TABLE ... AS SELECT` 로 생성.
- **쿼리 허용**: 앱에서 테이블별 쿼리를 제한하는 경우, 생성한 I1_ 테이블을 `Env/config/config.json` 의 `backend.allowed_tables` 에 추가해야 조회 가능.
