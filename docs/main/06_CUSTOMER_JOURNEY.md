# 고객 여정 맵 (최종 v2)

**용도**: Phase 0~12까지 역할·부서·ETL·프로젝트·로그인 흐름을 순서대로 정리한다. 권한 세부는 **`05_Permission_ARCHITECTURE.md`** 를 본다.

---

## Phase 0: 시스템 부트스트랩 (최초 1회) — SA_DEV

1. `dptmt_info` id=0 숨김 부서 시드 INSERT  
2. `user_info`에 SA_DEV 계정 시드(`dptmt_info_id=0`, `user_dvsn='sa_dev'`)  
3. 로그인 → 2차 인증 → 시스템 접속  

---

## Phase 1: 전사 인프라 세팅 (SA_DEV ↔ E)

**SA_DEV**

4. 최상위 부서 생성(id=1~)  
5. E(ETL Manager) 초대 → 이메일, `user_dvsn='etl_manager'`, 부서는 0 또는 전용 부서 → 초대 메일  

**E**

6. 초대 URL 가입  
7. 로그인 + 2차 인증  
8. ETL 인프라 구축(커넥션, 테이블 등록, Job 등)  

---

## Phase 2: 부서 SA 세팅 (SA_DEV ↔ 부서 SA)

**SA_DEV**

9. 부서 SA 초대 → 이메일·부서·SA 선택, 해당 부서에 이미 SA 있으면 컨펌 → 초대 메일  

**부서 SA**

10. 초대 URL 가입  
11. 로그인 + 2차 인증  

---

## Phase 3: 부서 내 인원 확보 (SA → A → O/U)

**부서 SA**

12. SA 또는 A 초대 → 초대 메일  

**A**

13. 초대 URL 가입  
14. 로그인 + 2차 인증  
15. O/U 초대(O/U 선택, U 선택 시 권한 세팅 창) → 초대 메일  

**O / U**

16. 가입  
17. 로그인  

**초대 시 선택 가능 Role (백엔드 제어)**

| 초대자 | 선택 가능 Role |
|--------|----------------|
| SA_DEV | E, SA, A, O, U |
| SA | SA, A, O, U(E 없음) |
| A | O, U(SA·E 없음) |
| O, U | 가입 초대 불가 |

---

## Phase 4: 로그인 (전 Role 공통)

18. 이메일 + 비밀번호  
19. `pre_auth_token` + 인증코드 이메일(5분)  
20. 인증코드 입력  
21. `access_token`(30분) + `refresh_token`(7일) → `session_log`·`user_login_log` INSERT  

**세션**: 슬라이딩 리프레시. 7일 연속 미접속 시 만료 → 재로그인.

---

## Phase 5: ETL 운영 (E 전담, 전사 공통)

**SA_DEV / E**: DB·스토리지·폴더 커넥션 CRUD, ETL 테이블·변환 룰, Job·배치·실행·이력, 적재 완료 시 `table_master` 자동 INSERT(전사 공통), 논리명·설명 편집.

**SA / A / O / U**: ETL 인프라 API 사용 불가.

---

## Phase 6: 프로젝트 생성·테이블 매핑

**SA_DEV / SA / A**: 본인 권한 범위에서 프로젝트 생성, `table_master` 전체 조회(전사 공통), 프로젝트↔테이블 매핑.

**O / U**: 해당 단계에서 생성·매핑 주체 아님(매트릭스 참고).

---

## Phase 7: 프로젝트 멤버 구성·운영 위임

**SA / A**: 멤버 초대(전역 active 유저 검색), 역할 지정(O 운영 위임 등).

**O / U**: 알림(프로젝트 초대 등).

### Phase 7-1: O의 위임 운영

**O**: 프로젝트 명/설명 수정, 멤버 초대·강퇴, **U** 멤버 권한 변경만.

**멤버 권한 변경 가능 범위**

| 변경자 | 대상 |
|--------|------|
| SA_DEV | 전체 |
| SA | A, O, U(본인 부서 프로젝트) |
| A | O, U(본인 부서 프로젝트) |
| O | U만(본인 운영 프로젝트) |
| U | 불가 |

---

## Phase 8: 프로젝트 진입·업무

**SA / A / O / U**: 메인 → 참여 프로젝트 카드 → 프로젝트 선택 시 JWT 재발급(`project_info_id`) → 쿼리스튜디오(매핑 테이블)·쿼리 실행·대시보드·위젯보드.

**E**: 프로젝트 내 기능 접근 불가.

**SA_D·SA·A**: 참여 프로젝트에서 보고 기능 자동 부여. **O·U**: `pmssn_master` 권한.

---

## Phase 9: 마이페이지 (전 Role)

프로필, 비밀번호 변경(전체 세션 만료), 로그인 이력(최근 10건, IP 마스킹).

---

## Phase 10: 알림 (전 Role)

벨·목록·읽음 처리.

---

## Phase 11: 관리·감독

**SA_DEV**: 전체 유저·전체 부서 CRUD·전체 프로젝트 감독·시스템 역할.

**SA**: 본인 부서 유저, 정지·활성·강제 로그아웃·role 변경, 하위 부서 CRUD.

**A**: 본인 부서 유저, A 이하 정지·활성·강제 로그아웃·role 변경.

---

## Phase 12: 로그아웃 (전 Role)

로그아웃 → `session_log.refresh_exprtn_dtm = NOW()` → 토큰 폐기 → 로그인 화면.
